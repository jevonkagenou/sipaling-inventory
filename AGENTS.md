# SIPALING - Panduan Pengembangan Sistem

Sistem Inventaris Prediktif & Audit Log Terintegrasi.
Proyek PBL Kelompok 1 - SIB 3C, Jurusan Teknologi Informasi, Politeknik Negeri Malang.

## Aturan Pengembangan
1. **Frontend**: Vue 3 (Composition API), Inertia.js, Tailwind CSS, Shadcn Vue, Lucide Icons.
2. **Palet Warna Desain (Stitch AI)**:
   - Primary: `#2563EB` (Royal Blue)
   - Secondary: `#4F46E5` (Deep Indigo)
   - Tertiary: `#10B981` (Emerald Green - khusus status positif/stok/audit)
   - Neutral: `#0F172A` (Slate Navy)
3. **Autentikasi**: Registrasi publik dinonaktifkan (`/register` dialihkan ke `/login`). Login menggunakan gaya ID Card / Namecard.
4. **Perintah Build**: Gunakan `npm run build` untuk kompilasi frontend.
